# Pilot results, October 2026 (partial)

!!! warning "Partial run"
    The API key's usage limit stopped the pilot after 11 of 48 tasks had a result for every team.
    At that size no difference between the teams is measurable. The run resumes when the limit
    resets on 2026-11-01, and this page will be replaced by the full table.

Three teams of Claude Haiku 5.5 agents (Claude Code 2.1.310), run on the same fresh tasks:

| Team | Spec | Resolved | Rate (95% CI) | Mean cost/task | Median wall time |
|---|---|---|---|---|---|
| solo | `solo:worker=claude@claude-haiku-5-5` | 2/11 | 18.2% (5.1%–47.7%) | $0.062 | 2.1 min |
| review | `review:coder=…,reviewer=…` (3 rounds) | 3/11 | 27.3% (9.7%–56.6%) | $0.057 | 3.3 min |
| best of 3 | `best:workers=…+…+…` (Haiku judge) | 2/11 | 18.2% (5.1%–47.7%) | $0.18 | 5.4 min |

Compared with solo on the same 11 tasks, review won 1 and lost none, and best of 3 won and lost
none (exact McNemar p = 1.0 for both). The single difference is `playcanvas__engine-9002`, which
only the review team resolved, but its reviewer approved the coder's first patch there: the win
came from a different coder rollout, not from review. All three teams resolved
`biomejs__biome-10853` and `floci-io__floci-1838`; no team resolved the other 8 (C#, Java, Rust,
C++).

Best of 3 cost three times as much per task as solo without resolving more tasks. Review cost
about the same as solo: its reviewer approved the first patch on 10 of 11 tasks (scores 7 to 9 of
10), so it ran one round; on `Ombi-app__Ombi-5444` it asked for one fix, and the fix still failed
the hidden tests.

## Setup

- **Tasks.** [SWE-bench-Live MultiLang](https://huggingface.co/datasets/SWE-bench-Live/MultiLang),
  created on or after 2026-07-01, after the June 2026 training cutoff Anthropic documents for its
  current models. A seeded sample of 70 (seed 7) was validated with the reference patches on Modal:
  48 valid, 16 invalid (the reference fix fails there, for example c-ares' IPv6 tests), 6 grading
  errors. The pilot ran on the 48 valid tasks.
- **Grading.** The dataset's hidden tests and log parsers in a clean sandbox of the instance image,
  ported line for line from SWE-bench-Live; agents never see the tests. See
  [the benchmark guide](../agent/bench/README.md).
- **Runtime.** Modal sandboxes (4 vCPU, 16 GB), driven by a detached Modal function
  (`python -m agent.bench remote run ...`), 2026-10-29.
- **Cost** is Claude Code's own `total_cost_usd` at API list prices. Modal compute is not included.

## What stopped it

At 19:09 UTC the Anthropic key reached its usage limit. From then on every agent exited after
about two seconds with `API Error: 400 You have reached your specified API usage limits` and used
no tokens. Those 106 pairs are marked as errors in the published data and excluded for every team,
which is why only 11 tasks are compared. The run that produced them predates the fix (#92) that
now records such pairs as errors automatically, so they were relabelled with the same rule before
publishing: a failed agent run that used no input or output tokens.

## Data

Everything is in
[`results/2026-10-haiku-pilot/`](https://github.com/BichengWang/multi-agents/tree/main/results/2026-10-haiku-pilot):

| File | Contents |
|---|---|
| `report.md` | The full report from `python -m agent.bench report`, including every excluded pair |
| `results.jsonl.gz` | One record per task × team: patch, usage, cost, timing, grading details, errors |
| `artifacts.tar.gz` | Raw trajectories: `artifacts/<team>/<task>/{patch.diff,runs.json,eval.log}` |
| `gold.jsonl` | Reference-patch validation of the 70 sampled tasks |
| `meta.json` | Filters, seed, dataset revision, teams and budget of the run |

To regenerate the report:

```bash
mkdir pilot && cd pilot
cp ../results/2026-10-haiku-pilot/meta.json . && gunzip -c ../results/2026-10-haiku-pilot/results.jsonl.gz > results.jsonl
python -m agent.bench report . --baseline solo:worker=claude@claude-haiku-5-5
```

Stored text was scrubbed of credentials before writing (values of credential variables and
key-shaped strings). The six `[REDACTED]` marks in the data are false positives inside test logs.
